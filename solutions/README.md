# Musterlösungen

Dieses Verzeichnis enthält Musterlösungen für die Aufgaben und Projekte der Kursabende 4 und 5.

## ⚠️ Wichtiger Hinweis

Diese Lösungen sind **Beispiele** und zeigen **einen** möglichen Lösungsweg. Es gibt oft mehrere richtige Wege, ein Problem zu lösen!

**Empfehlung:** Versuche zuerst selbst eine Lösung zu finden, bevor du hier nachschaust.

## Struktur

### kursabend-4/

Musterlösungen für die Übungsaufgaben von Kursabend 4:

**Level 1: Aufwärmen**
- `aufgabe_1_1_zahlenraten_highscore.py` - Zahlenraten mit Highscore-Funktion
- `aufgabe_1_2_einkaufsliste.py` - Einkaufsliste mit Speicherfunktion
- `aufgabe_1_3_notizen_app.py` - Notizen-App mit Zeitstempel

**Level 2: Herausforderung**
- `aufgabe_2_1_textanalyse.py` - Textanalyse-Tool
- `aufgabe_2_2_csv_verarbeitung.py` - CSV-Verarbeitung für Produktdaten
- `aufgabe_2_3_log_analyzer.py` - Log-File-Analyzer

**Level 3: Für Schnelle**
- `aufgabe_3_1_vokabeltrainer.py` - Vokabeltrainer mit Statistik
- `aufgabe_3_2_kontaktverwaltung.py` - Kontaktverwaltung

### kursabend-5/

Musterlösungen für die Mini-Projekte von Kursabend 5:

- `projekt_1_tagebuch.py` - Digitales Tagebuch
- `projekt_3_quiz.py` - Quiz-Generator

## Verwendung

### Programme ausführen

```bash
# Mit Python direkt
python solutions/kursabend-4/aufgabe_1_1_zahlenraten_highscore.py

# Mit uv
uv run python solutions/kursabend-4/aufgabe_1_1_zahlenraten_highscore.py
```

### Code studieren

Öffne die Dateien in deinem Editor und studiere:

1. **Struktur:** Wie ist der Code organisiert?
2. **Funktionen:** Welche Funktionen werden verwendet?
3. **Kommentare:** Was erklären die Kommentare?
4. **Fehlerbehandlung:** Wie werden Fehler behandelt?

## Lernansatz

### Schritt 1: Selbst versuchen

Versuche die Aufgabe zuerst selbst zu lösen, ohne die Musterlösung anzuschauen.

### Schritt 2: Vergleichen

Wenn du eine eigene Lösung hast, vergleiche sie mit der Musterlösung:

- Was ist ähnlich?
- Was ist unterschiedlich?
- Welche Lösung ist besser lesbar?
- Welche Lösung ist effizienter?

### Schritt 3: Verstehen

Wenn du etwas in der Musterlösung nicht verstehst:

1. Lies die Kommentare
2. Schaue die Dokumentation nach
3. Frage deinen Dozenten oder Mitstudierenden

### Schritt 4: Experimentieren

Verändere die Musterlösung:

- Füge neue Funktionen hinzu
- Verbessere die Benutzeroberfläche
- Optimiere den Code

## Unterschiede zu deiner Lösung?

Das ist völlig normal! Wichtig ist:

✅ Dein Code funktioniert  
✅ Dein Code ist lesbar  
✅ Du verstehst, was dein Code macht

Verschiedene Lösungswege sind ein Zeichen von Kreativität!

## Fragen?

Bei Fragen zu den Musterlösungen:

2. Notiere deine Frage
3. Bringe sie zum nächsten Kursabend mit
4. Oder stelle sie im Moodle-Forum

## Code-Qualität

Die Musterlösungen zeigen:

- ✅ Sprechende Variablennamen
- ✅ Hilfreiche Kommentare
- ✅ Docstrings für Funktionen
- ✅ Fehlerbehandlung mit try-except
- ✅ Saubere Formatierung
- ✅ Modulare Struktur mit Funktionen

Versuche, diese Prinzipien in deinem eigenen Code anzuwenden!
