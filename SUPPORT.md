## 🐛 Probleme melden

### Was sollte ein guter Bug Report enthalten?

1. **Klare Beschreibung** des Problems
2. **Schritte zur Reproduktion**
3. **Erwartetes vs. tatsächliches Verhalten**
4. **Umgebungsinformationen**:
   - Betriebssystem
   - Python-Version
   - IDE
5. **Screenshots** (falls hilfreich)
6. **Fehlermeldungen** (vollständig)

### Beispiel

```markdown
## Problem
Die Palindrom-Funktion gibt False zurück, obwohl der Input ein Palindrom ist.

## Schritte zur Reproduktion
1. Datei `exercise/palindrom.py` öffnen
2. Funktion mit "anna" aufrufen
3. Ergebnis ist False statt True

## Umgebung
- OS: macOS 14.0
- Python: 3.13.0
- IDE: VS Code

## Fehlermeldung
Keine Fehlermeldung, nur falsches Ergebnis.
```

## 📋 Häufig gestellte Fragen (FAQ)

### Kann ich das Kursmaterial für eigene Zwecke verwenden?

Ja! Das Projekt ist unter der MIT-Lizenz veröffentlicht. Sie können es frei verwenden, modifizieren und weitergeben.

### Wie kann ich zum Projekt beitragen?

Siehe [CONTRIBUTING.md](CONTRIBUTING.md) für eine detaillierte Anleitung.

### Meine lokale Umgebung funktioniert nicht. Was soll ich tun?

Nutzen Sie eine der Backup-Umgebungen (Codespaces oder Gitpod). Siehe `docs/exercises/backup-environments-quickstart.adoc`.

### Kann ich direkt auf main oder develop pushen?

Nein, diese Branches sind geschützt. Erstellen Sie einen Feature-Branch und einen Pull Request.

### Wo finde ich die Lösungen zu den Übungen?

Die Musterlösungen befinden sich im `solutions/` Verzeichnis.
