== Dateiverarbeitung: Die Grundlagen

=== Dateien lesen

Um eine Datei zu lesen, verwenden wir die Funktion `open()` zusammen mit einem `with`-Statement:

[source,python]
----
# Datei lesen
with open('meine_datei.txt', 'r', encoding='utf-8') as datei:
    inhalt = datei.read()
    print(inhalt)
----

Das `with`-Statement stellt sicher, dass die Datei automatisch geschlossen wird.

=== Dateien schreiben

Um in eine Datei zu schreiben:

[source,python]
----
# Datei schreiben
with open('ausgabe.txt', 'w', encoding='utf-8') as datei:
    datei.write('Hallo Welt!\n')
    datei.write('Dies ist die zweite Zeile.\n')
----

[WARNING]
====
Der Modus `'w'` überschreibt die Datei komplett! Verwende `'a'` zum Anhängen.
====

=== Dateien zeilenweise lesen

Oft möchten wir eine Datei Zeile für Zeile verarbeiten:

[source,python]
----
with open('meine_datei.txt', 'r', encoding='utf-8') as datei:
    for zeile in datei:
        zeile = zeile.strip()  # Entfernt Leerzeichen und Zeilenumbrüche
        print(zeile)
----

==== Aufgabe 2.2: CSV-Verarbeitung

Erstelle ein Programm, das einfache CSV-Daten (Comma-Separated Values) verarbeitet.

*Anforderungen:*

* Lies eine CSV-Datei mit Produktdaten ein (`produkte.csv`)
* Format: `Name,Preis,Anzahl`
* Berechne:
  - Gesamtwert aller Produkte (Preis × Anzahl)
  - Durchschnittspreis
  - Teuerstes Produkt
  - Günstigstes Produkt
* Erstelle einen Bericht

*Beispiel produkte.csv:*

----
Apfel,1.50,10
Banane,0.80,15
Orange,2.00,8
Birne,1.80,12
----

*Hilfestellung:*

[source,python]
----
def lese_csv(dateiname):
    """Liest CSV-Datei und gibt Liste von Produkten zurück."""
    produkte = []
    with open(dateiname, 'r', encoding='utf-8') as datei:
        for zeile in datei:
            zeile = zeile.strip()
            teile = zeile.split(',')
            
            produkt = {
                'name': teile[0],
                'preis': float(teile[1]),
                'anzahl': int(teile[2])
            }
            produkte.append(produkt)
    
    return produkte
----
