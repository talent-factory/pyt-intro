==== Automatisierung & Skripte 🤖

**Was man damit machen kann:**

* Wiederkehrende Aufgaben automatisieren
* Dateien organisieren und verarbeiten
* System-Administration

**Beispiel-Projekt:**
[source,python]
----
import os
import shutil
from datetime import datetime

def organisiere_fotos(ordner):
    """Organisiert Fotos nach Datum."""
    for datei in os.listdir(ordner):
        if datei.endswith('.jpg'):
            # Datum aus Dateiname extrahieren
            datum = datei.split('_')[0]
            ziel_ordner = f'organisiert/{datum}'
            os.makedirs(ziel_ordner, exist_ok=True)
            shutil.move(f'{ordner}/{datei}', f'{ziel_ordner}/{datei}')
----

==== Spiele & Grafik 🎮

**Was man damit machen kann:**

* Einfache 2D-Spiele entwickeln
* Grafische Benutzeroberflächen
* Animationen und Visualisierungen

**Wichtige Bibliotheken:**
* `pygame` - 2D-Spiele-Entwicklung
* `tkinter` - GUI-Entwicklung (eingebaut)
* `pyglet` - Multimedia-Anwendungen

**Beispiel-Projekt:**
[source,python]
----
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Mein erstes Spiel")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    
    screen.fill((255, 255, 255))  # Weisser Hintergrund
    pygame.draw.circle(screen, (255, 0, 0), (400, 300), 50)  # Roter Kreis
    pygame.display.flip()

pygame.quit()
----
