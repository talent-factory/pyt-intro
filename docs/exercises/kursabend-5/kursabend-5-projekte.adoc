== Projekt 1: Digitales Tagebuch

=== Projektbeschreibung

Erstelle eine Tagebuch-Anwendung, in der Benutzer tägliche Einträge schreiben, speichern und später wieder lesen können.

=== Mindestanforderungen (Pflicht)

* Neuen Tagebucheintrag erstellen
* Einträge werden mit Datum und Uhrzeit gespeichert
* Alle Einträge anzeigen
* Einträge in Dateien speichern
* Benutzerfreundliches Menü

=== Erweiterte Funktionen (Optional)

* Nach Datum suchen
* Stimmung/Emoji zum Eintrag hinzufügen (😊, 😐, 😢)
* Tags/Kategorien für Einträge (z.B. #arbeit, #freizeit)
* Statistik: Anzahl Einträge pro Monat
* Einträge bearbeiten oder löschen
* Exportfunktion (alle Einträge in eine Datei)

=== Technische Hinweise

*Dateistruktur:*

----
tagebuch/
├── eintraege/
│   ├── 2025-10-15.txt
│   ├── 2025-10-16.txt
│   └── ...
└── tagebuch.py
----

== Projekt 2: Ausgaben-Tracker

=== Projektbeschreibung

Erstelle eine Anwendung zur Verwaltung persönlicher Ausgaben. Benutzer können Ausgaben erfassen, kategorisieren und auswerten.

=== Mindestanforderungen (Pflicht)

* Ausgabe erfassen (Datum, Kategorie, Betrag, Beschreibung)
* Alle Ausgaben anzeigen
* Ausgaben nach Kategorie filtern
* Gesamtsumme berechnen
* Daten in Datei speichern

=== Erweiterte Funktionen (Optional)

* Monatsübersicht (Ausgaben pro Monat)
* Kategoriestatistik (welche Kategorie kostet am meisten?)
* Budget setzen und Warnung bei Überschreitung
* Ausgaben bearbeiten/löschen
* Export als CSV-Datei
* Diagramm als ASCII-Art (Balkendiagramm)

=== Technische Hinweise

*Kategorien-Vorschläge:*

* Lebensmittel
* Transport
* Freizeit
* Wohnen
* Gesundheit
* Sonstiges

*Beispiel-Code für den Start:*

[source,python]
----
from datetime import datetime

def erfasse_ausgabe():
    """Erfasst eine neue Ausgabe."""
    print("\n=== Neue Ausgabe erfassen ===")
    
    kategorien = ['Lebensmittel', 'Transport', 'Freizeit', 
                  'Wohnen', 'Gesundheit', 'Sonstiges']
    
    print("\nKategorien:")
    for i, kat in enumerate(kategorien, 1):
        print(f"{i}. {kat}")
    
    kat_nr = int(input("\nKategorie wählen (1-6): "))
    kategorie = kategorien[kat_nr - 1]
    
    betrag = float(input("Betrag (CHF): "))
    beschreibung = input("Beschreibung: ")
    
    datum = datetime.now().strftime('%Y-%m-%d')
    
    # Speichere in Datei
    with open('ausgaben.txt', 'a', encoding='utf-8') as datei:
        datei.write(f"{datum}|{kategorie}|{betrag}|{beschreibung}\n")
    
    print(f"✓ Ausgabe von CHF {betrag:.2f} gespeichert!")

def zeige_ausgaben():
    """Zeigt alle Ausgaben an."""
    try:
        with open('ausgaben.txt', 'r', encoding='utf-8') as datei:
            print("\n=== Alle Ausgaben ===")
            print(f"{'Datum':<12} {'Kategorie':<15} {'Betrag':>10} {'Beschreibung'}")
            print("-" * 60)
            
            gesamt = 0
            for zeile in datei:
                datum, kategorie, betrag, beschreibung = zeile.strip().split('|')
                betrag_float = float(betrag)
                gesamt += betrag_float
                print(f"{datum:<12} {kategorie:<15} CHF {betrag_float:>7.2f} {beschreibung}")
            
            print("-" * 60)
            print(f"{'Gesamt:':<27} CHF {gesamt:>7.2f}")
    
    except FileNotFoundError:
        print("Noch keine Ausgaben erfasst.")

== Projekt 4: Passwort-Generator und -Manager

=== Projektbeschreibung

Erstelle ein Programm, das sichere Passwörter generiert und diese optional speichert.

=== Mindestanforderungen (Pflicht)

* Passwort generieren mit wählbarer Länge
* Verschiedene Zeichentypen (Buchstaben, Zahlen, Sonderzeichen)
* Passwort-Stärke anzeigen
* Generierte Passwörter anzeigen
* Optional: Passwörter mit Beschreibung speichern

=== Erweiterte Funktionen (Optional)

* Passwort-Manager (Passwörter mit Service-Namen speichern)
* Einfache Verschlüsselung (z.B. Caesar-Chiffre)
* Passwort-Stärke-Checker für eigene Passwörter
* Mehrere Passwörter auf einmal generieren
* Passwort-Historie
* Passwörter nach Service durchsuchen

=== Technische Hinweise

*Passwort-Stärke-Kriterien:*

* Schwach: < 8 Zeichen, nur Buchstaben
* Mittel: 8-12 Zeichen, Buchstaben + Zahlen
* Stark: > 12 Zeichen, Buchstaben + Zahlen + Sonderzeichen

*Beispiel-Code für den Start:*

[source,python]
----
import random
import string

def generiere_passwort(laenge=12, gross=True, klein=True, 
                       zahlen=True, sonderzeichen=True):
    """Generiert ein zufälliges Passwort."""
    zeichen = ''
    
    if gross:
        zeichen += string.ascii_uppercase
    if klein:
        zeichen += string.ascii_lowercase
    if zahlen:
        zeichen += string.digits
    if sonderzeichen:
        zeichen += '!@#$%^&*()_+-=[]{}|;:,.<>?'
    
    if not zeichen:
        return "Fehler: Mindestens eine Zeichenart wählen!"
    
    passwort = ''.join(random.choice(zeichen) for _ in range(laenge))
    return passwort

def pruefe_staerke(passwort):
    """Prüft die Stärke eines Passworts."""
    laenge = len(passwort)
    hat_gross = any(c.isupper() for c in passwort)
    hat_klein = any(c.islower() for c in passwort)
    hat_zahl = any(c.isdigit() for c in passwort)
    hat_sonder = any(c in '!@#$%^&*()_+-=[]{}|;:,.<>?' for c in passwort)
    
    punkte = 0
    if laenge >= 8:
        punkte += 1
    if laenge >= 12:
        punkte += 1
    if hat_gross:
        punkte += 1
    if hat_klein:
        punkte += 1
    if hat_zahl:
        punkte += 1
    if hat_sonder:
        punkte += 1
    
    if punkte <= 2:
        return "Schwach ⚠️"
    elif punkte <= 4:
        return "Mittel 🔶"
    else:
        return "Stark ✅"

def speichere_passwort(service, passwort):
    """Speichert ein Passwort mit Service-Namen."""
    with open('passwoerter.txt', 'a', encoding='utf-8') as datei:
        datei.write(f"{service}|{passwort}\n")
    print(f"✓ Passwort für '{service}' gespeichert!")

def hauptmenu():
    """Hauptmenü des Passwort-Generators."""
    while True:

            staerke = pruefe_staerke(passwort)
            
            print(f"\nGeneriertes Passwort: {passwort}")
            print(f"Stärke: {staerke}")

            break

if __name__ == '__main__':
