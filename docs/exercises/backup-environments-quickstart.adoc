== 🚨 Technische Probleme? Kein Problem!

Falls Ihre lokale Python-Installation nicht funktioniert, haben wir **zwei Backup-Lösungen** vorbereitet:

== Option 1: GitHub Codespaces ⚡

=== In 3 Schritten startklar:

1. **Repository auf GitHub öffnen**
2. **"Code" → "Codespaces" → "Create codespace"** klicken
3. **2 Minuten warten** - fertig! 🎉

=== Python-Umgebung einrichten:

[source,bash]
----
# Terminal in Codespace öffnen
# Abhängigkeiten installieren
uv sync

# Python-Version prüfen
python --version
----

=== Jupyter Notebook starten:

[source,bash]
----
# Jupyter Notebook starten
jupyter notebook

# Codespace öffnet automatisch den Port
# Klicken Sie auf "Open in Browser" wenn Popup erscheint
----

=== Python-Skript ausführen:

[source,bash]
----
# Beispiel-Skript ausführen
uv run python example.py

# Oder direkt mit Python
python main.py
----

== Option 2: Gitpod 🚀

=== Noch schneller:

1. **URL ändern:** `gitpod.io/#` vor GitHub-URL setzen
2. **Enter drücken** - startet automatisch
3. **1 Minute warten** - fertig! ⚡

=== Beispiel:
[source,text]
----
Aus: https://github.com/username/pyt-intro
Wird: https://gitpod.io/#https://github.com/username/pyt-intro
----

=== Umgebung ist vorkonfiguriert:

[source,bash]
----
# Alle Pakete sind bereits installiert
uv sync

# Python-Skript ausführen
uv run python example.py

# Jupyter Notebook starten
jupyter notebook
----

== 💡 Pro-Tipps

=== Für GitHub Codespaces:

* **VS Code Desktop** verwenden für bessere Performance

* **Ports Tab** beachten für Jupyter Notebooks

* **Environment Variables** im Dashboard setzen

== 📝 Git-Workflow für Code-Änderungen

=== Wichtig: Eigenen Branch erstellen!

Die Branches `main` und `develop` sind **geschützt** und können nicht direkt bearbeitet werden.

**Best Practice:** Erstellen Sie für Ihre Änderungen einen eigenen Feature-Branch.

=== Schritt-für-Schritt Anleitung:

**1. Eigenen Branch erstellen:**
[source,bash]
----
# Beschreibenden Namen wählen (z.B. feature/mein-name oder exercise/aufgabe-1)
git checkout -b feature/ihr-name
----

**2. Änderungen vornehmen und committen:**
[source,bash]
----
# Dateien zur Staging Area hinzufügen
git add .

# Commit mit aussagekräftiger Message
git commit -m "feat: Beschreibung der Änderung"
----

**3. Branch pushen:**
[source,bash]
----
# Beim ersten Push
git push -u origin feature/ihr-name

# Bei weiteren Commits
git push
----

=== 🔒 Branch-Namenskonventionen

Verwenden Sie aussagekräftige Präfixe:

* `feature/ihr-name` - Für neue Features oder Übungen
* `exercise/aufgabe-nr` - Für spezifische Kursaufgaben
* `fix/beschreibung` - Für Bugfixes
* `experiment/thema` - Für Experimente

=== ⚠️ Wichtige Hinweise

* **Niemals direkt auf `main` oder `develop` pushen** - Diese Branches sind geschützt
* **Regelmässig committen** - So gehen keine Änderungen verloren
* **Aussagekräftige Commit-Messages** - Folgen Sie dem Format: `type: Beschreibung`
* **Eigene Branches** - Jeder Studierende arbeitet auf seinem eigenen Branch

=== 💾 Änderungen sichern

Ihre Arbeit bleibt in Codespaces/Gitpod erhalten, solange:

* Sie **regelmässig committen**
* Sie **auf Ihren eigenen Branch pushen**
* Der Workspace **nicht gelöscht** wird

[TIP]
====
**Tipp:** Committen Sie nach jeder abgeschlossenen Teilaufgabe, nicht erst am Ende!
====

== 🔧 Häufige Probleme und Lösungen

=== Problem: Jupyter Notebook startet nicht

**Lösung:**
[source,bash]
----
# Jupyter neu installieren
uv add jupyter

# Oder direkt mit pip
pip install jupyter notebook
----

=== Problem: Python-Skript findet Module nicht

**Lösung:**
[source,bash]
----
# Abhängigkeiten neu installieren
uv sync

# Oder mit uv run ausführen
uv run python ihr-skript.py
----

=== Problem: Port ist nicht erreichbar

**Lösung:**

1. **Ports Tab** in VS Code prüfen
2. **Port 8888** (Jupyter) sollte automatisch weitergeleitet werden
3. **"Open in Browser"** klicken

=== Problem: Git-Befehle funktionieren nicht

**Lösung:**
[source,bash]
----
# Git-Konfiguration prüfen
git config --list

# Name und E-Mail setzen
git config --global user.name "Ihr Name"
git config --global user.email "ihre.email@example.com"
----

== 📚 Wichtige Befehle im Überblick

=== Python ausführen:
[source,bash]
----
# Mit uv (empfohlen)
uv run python skript.py

# Direkt mit Python
python skript.py

# Interaktive Python-Shell
python
----

=== Jupyter Notebook:
[source,bash]
----
# Notebook starten
jupyter notebook

# Notebook zu Python konvertieren
jupyter nbconvert --to python notebook.ipynb
----

=== Package Management:
[source,bash]
----
# Abhängigkeiten installieren
uv sync

# Paket hinzufügen
uv add paketname

# Alle installierten Pakete anzeigen
uv pip list
----

[source,bash]
----

git status

# Änderungen anzeigen
git diff

# Branch wechseln
git checkout branch-name

# Änderungen vom Remote holen
git pull
----
