Ein Dictionary in Python ist eine Datenstruktur, die eine Sammlung von Schlüssel-Wert-Paaren enthält.
Jeder Schlüssel im Dictionary muss eindeutig sein und kann mit einem bestimmten Wert verknüpft werden.
Im Python-Code wird ein Dictionary mit geschweiften Klammern {} und einem Doppelpunkt : zwischen Schlüssel und Wert erstellt.

[source,python,numbers]
----
mein_dictionary = {
    "Name": "Peter",
    "Alter": 28,
    "Stadt": "Bern"
}
----
