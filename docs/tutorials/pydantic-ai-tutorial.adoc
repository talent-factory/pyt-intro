== Einführung

=== Was ist KI-Integration mit Pydantic?

Dieses Tutorial zeigt, wie die Datenvalidierung und -strukturierung von Pydantic mit KI-Fähigkeiten verbunden werden kann. Diese Integration ermöglicht es Entwicklern, auf einfache Weise KI-gestützte Funktionen in ihre Python-Anwendungen einzubinden, während sie weiterhin die Vorteile von Pydantics Typsicherheit und Datenvalidierungsmechanismen nutzen können.

====
Dieses Tutorial baut auf dem Hauptteil des Pydantic-Tutorials auf. Wenn Sie mit den Grundlagen von Pydantic noch nicht vertraut sind, empfehlen wir Ihnen, zuerst das Haupttutorial zu Pydantic zu bearbeiten.

=== Datenmodelle mit Pydantic

Pydantic ist eine Bibliothek zur Datenvalidierung und -einschränkung, die auf Python-Typannotationen basiert. Mit Pydantic können Sie Datenmodelle definieren, die automatisch validiert werden.

[source,python]
----
from pydantic import BaseModel, Field, validator
from typing import List, Optional
from datetime import date

class User(BaseModel):
    id: int
    name: str = Field(..., min_length=2)
    email: str
    birthdate: Optional[date] = None
    interests: List[str] = []
    
    @validator('email')
    def email_must_be_valid(cls, v):
        if '@' not in v:
            raise ValueError('Email muss ein @-Zeichen enthalten')
        return v.lower()

# Beispielnutzung
user = User(id=1, name="Anna", email="anna@example.com")
print(user.json())
----

=== Vorteile von Pydantic

* **Typsicherheit**: Automatische Validierung und Konvertierung von Daten basierend auf Typannotationen
* **Fehlermeldungen**: Klare und aussagekräftige Fehlermeldungen bei Validierungsfehlern
* **Serialisierung/Deserialisierung**: Einfache Konvertierung zwischen Python-Objekten und JSON
* **IDE-Integration**: Bessere Code-Vervollständigung und Typüberprüfung in IDEs
* **Erweiterbarkeit**: Einfach durch benutzerdefinierte Validatoren und Field-Typen zu erweitern

=== Sentimentanalyse

[source,python]
----
from pydantic import BaseModel, Field
from pydanticai import AIField, ai_method
from typing import List, Dict

# Reale Implementierung mit LangChain und Pydantic
class SentimentAnalyzer(BaseModel):
    text: str
    sentiment: Optional[str] = Field(None, description="Die allgemeine Stimmung des Textes (positiv, neutral, negativ)")
    confidence: Optional[float] = Field(None, description="Konfidenzwert der Sentimentanalyse zwischen 0 und 1")
    aspects: Optional[dict] = Field(None, description="Aspekte des Textes und deren Stimmung")
    
    def analyze(self):
        """Führt die Sentimentanalyse mit LangChain durch"""
        prompt = PromptTemplate(
            input_variables=["text"],
            template="""Analysiere den folgenden Text und gib das Ergebnis im JSON-Format zurück:
            Text: {text}
            
            Format:
            {{
                "sentiment": "positiv|neutral|negativ",
                "confidence": <float zwischen 0 und 1>,
                "aspects": {{
                    "<aspekt1>": "positiv|neutral|negativ",
                    "<aspekt2>": "positiv|neutral|negativ"
                }}
            }}
            """
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        result = chain.run(text=self.text)
        
        # In einer realen Anwendung würden Sie hier die JSON-Antwort parsen
        # und die Attribute des Modells aktualisieren
        import json
        try:
            analysis = json.loads(result)
            self.sentiment = analysis.get("sentiment")
            self.confidence = analysis.get("confidence")
            self.aspects = analysis.get("aspects")
        except json.JSONDecodeError:
            # Fallback für den Fall, dass die Antwort kein gültiges JSON ist
            self.sentiment = "unbekannt"
            self.confidence = 0.0
            self.aspects = {}
        
        return self
    
    def get_emotional_tone(self) -> List[str]:
        """Identifiziert die emotionalen Töne im Text"""
        prompt = PromptTemplate(
            input_variables=["text"],
            template="""Identifiziere die emotionalen Töne im folgenden Text und gib sie als Liste zurück:
            Text: {text}
            
            Emotionale Töne:"""
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        result = chain.run(text=self.text)
        
        # Einfache Verarbeitung des Ergebnisses
        tones = [tone.strip() for tone in result.split(',')]
        return tones
    
    def suggest_response(self, tone: str = "neutral") -> str:
        """Generiert eine Antwort im gewünschten Ton"""
        prompt = PromptTemplate(
            input_variables=["text", "tone"],
            template="""Generiere eine Antwort auf den folgenden Text im {tone}n Ton:
            Text: {text}
            
            Antwort:"""
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        return chain.run(text=self.text, tone=tone)

== Anwendungsfall 4: Kontextbewusste KI-Assistenten

=== Persönlicher Assistent

[source,python]
----
from pydantic import BaseModel, Field
from pydanticai import AIModel, ai_method, AIState
from typing import List, Dict, Optional
from datetime import datetime, date
import uuid
import langchain
from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain
from langchain.prompts import PromptTemplate

# Verweis auf den Hauptteil des Pydantic-Tutorials für Grundlagen der Modellierung
# Siehe: Abschnitt "Grundlegende Konzepte" im Pydantic-Tutorial

class Task(BaseModel):
    """Repräsentiert eine Aufgabe im persönlichen Assistenten.
    Verwendet Pydantic für Typsicherheit und Validierung."""
    id: str = Field(default_factory=lambda: str(uuid.uuid4()))
    description: str
    due_date: Optional[date] = None
    priority: int = Field(1, ge=1, le=5)  # 1-5, mit Validierung
    completed: bool = False
    
    class Config:
        validate_assignment = True  # Validiert auch nach der Erstellung

class PersonalAssistant(BaseModel):
    """Ein KI-gestützter persönlicher Assistent mit Konversationsgedächtnis."""
    user_name: str
    conversation_history: List[Dict[str, str]] = []
    tasks: List[Task] = []
    preferences: Dict[str, str] = {}
    
    # LangChain-Komponenten für KI-Funktionalität
    _memory: Optional[ConversationBufferMemory] = None
    _conversation: Optional[ConversationChain] = None
    
    def __init__(self, **data):
        super().__init__(**data)
        # Initialisierung des Konversationsgedächtnisses
        self._memory = ConversationBufferMemory()
        self._conversation = ConversationChain(
            llm=llm,
            memory=self._memory,
            prompt=PromptTemplate(
                input_variables=["history", "input"],
                template="""Du bist ein hilfreicher persönlicher Assistent für {user_name}.
                
Gesprächsverlauf:
{history}

Benutzer: {input}
Assistent:""".format(user_name=self.user_name, history="{history}", input="{input}")
            )
        )
    
    def respond_to_query(self, query: str) -> str:
        """Antwortet auf eine Benutzeranfrage basierend auf dem Konversationsverlauf."""
        # Fügt die Anfrage zum Verlauf hinzu
        self.conversation_history.append({"user": query, "timestamp": datetime.now().isoformat()})
        
        # Verwendet LangChain für die Antwortgenerierung
        response = self._conversation.predict(input=query)
        
        # Speichert die Antwort im Verlauf
        self.conversation_history.append({"assistant": response, "timestamp": datetime.now().isoformat()})
        
        return response
    
    def add_task_from_description(self, description: str) -> Task:
        """Erstellt eine neue Aufgabe aus einer Beschreibung und extrahiert Fälligkeitsdatum und Priorität."""
        prompt = PromptTemplate(
            input_variables=["description"],
            template="""Extrahiere aus der folgenden Aufgabenbeschreibung das Fälligkeitsdatum (falls vorhanden) und die Priorität (1-5).
            
Beschreibung: {description}

Antworte im JSON-Format:
{{
    "description": "bereinigte Beschreibung ohne Datum/Priorität",
    "due_date": "YYYY-MM-DD oder null",
    "priority": Zahl zwischen 1 und 5
}}"""
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        result = chain.run(description=description)
        
        # In einer realen Anwendung würden Sie hier die JSON-Antwort parsen
        # und die Attribute des Modells aktualisieren
        import json
        try:
            task_data = json.loads(result)
            task = Task(
                description=task_data.get("description", description),
                priority=task_data.get("priority", 1)
            )
            
            # Datum konvertieren, falls vorhanden
            due_date_str = task_data.get("due_date")
            if due_date_str and due_date_str.lower() != "null":
                task.due_date = date.fromisoformat(due_date_str)
                
            self.tasks.append(task)
            return task
        except (json.JSONDecodeError, ValueError):
            # Fallback bei Fehlern
            task = Task(description=description)
            self.tasks.append(task)
            return task
    
    def suggest_daily_plan(self) -> List[Dict[str, str]]:
        """Schlägt einen Tagesplan basierend auf den anstehenden Aufgaben vor."""
        # Aufgaben in ein Format konvertieren, das für den Prompt geeignet ist
        tasks_str = "\n".join([f"- {task.description} (Priorität: {task.priority})" 
                              for task in self.tasks if not task.completed])
        
        prompt = PromptTemplate(
            input_variables=["user_name", "tasks", "preferences"],
            template="""Erstelle einen Tagesplan für {user_name} basierend auf den folgenden Aufgaben und Vorlieben.
            
Aufgaben:
{tasks}

Vorlieben:
{preferences}

Gib den Plan als Liste von Zeitslots mit Aktivitäten zurück."""
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        preferences_str = "\n".join([f"- {k}: {v}" for k, v in self.preferences.items()])
        result = chain.run(user_name=self.user_name, tasks=tasks_str, preferences=preferences_str)
        
        # Einfache Verarbeitung des Ergebnisses für dieses Beispiel
        plan_items = []
        for line in result.split("\n"):
            if line.strip():
                plan_items.append({"activity": line.strip()})
        
        return plan_items
    
    def summarize_conversation(self) -> str:
        """Fasst die aktuelle Konversation zusammen."""
        # Konversation in ein Format konvertieren, das für den Prompt geeignet ist
        conversation_str = "\n".join([f"{entry.get('user', entry.get('assistant', ''))}" 
                                    for entry in self.conversation_history])
        
        prompt = PromptTemplate(
            input_variables=["conversation"],
            template="""Fasse die folgende Konversation zusammen:
            
{conversation}

Zusammenfassung:"""
        )
        
        chain = LLMChain(llm=llm, prompt=prompt)
        return chain.run(conversation=conversation_str)

== Ethik und Best Practices

=== Datenschutz und Sicherheit

Bei der Arbeit mit KI-Modellen ist es wichtig, Datenschutz und Sicherheit zu berücksichtigen:

* Vermeiden Sie die Übermittlung sensibler persönlicher Daten an KI-Modelle
* Implementieren Sie Datenfilterung und -anonymisierung
* Speichern Sie nur notwendige Daten und respektieren Sie die DSGVO

=== Bias und Fairness

KI-Modelle können Vorurteile aus ihren Trainingsdaten übernehmen:

* Seien Sie sich möglicher Vorurteile in den Ausgaben bewusst
* Implementieren Sie Überprüfungen und Gegenmaßnahmen
* Testen Sie mit diversen Eingaben

=== Transparenz

* Informieren Sie Benutzer darüber, wann KI im Einsatz ist
* Erklären Sie die Grenzen der KI-Funktionen
* Bieten Sie Möglichkeiten für menschliche Überprüfung und Eingriffe

== Glossar

[glossary]
KI-Modell:: Ein trainiertes System, das natürliche Sprache verarbeiten und generieren kann.
Pydantic:: Eine Python-Bibliothek zur Datenvalidierung und -einschränkung basierend auf Typannotationen.
LangChain:: Ein Framework zur Entwicklung von Anwendungen, die mit LLMs (Large Language Models) arbeiten.
LLM:: Large Language Model - ein großes Sprachmodell wie GPT-4, das natürliche Sprache verstehen und generieren kann.
Prompt Engineering:: Die Kunst, Eingabeaufforderungen für KI-Modelle zu gestalten, um die gewünschten Ergebnisse zu erzielen.
API-Schlüssel:: Ein geheimer Schlüssel, der den Zugriff auf KI-Dienste wie OpenAI ermöglicht.
Validierung:: Der Prozess der Überprüfung von Daten auf Korrektheit und Einhaltung definierter Regeln.
Serialisierung:: Die Umwandlung von Objekten in ein Format, das gespeichert oder übertragen werden kann.
Deserialisierung:: Die Umwandlung von serialisierten Daten zurück in Objekte.
Token:: Die grundlegende Einheit, in die Text für LLMs aufgeteilt wird. Die Anzahl der Token beeinflusst Kosten und Leistung.
Embedding:: Eine numerische Darstellung von Text, die semantische Bedeutung erfasst und für Ähnlichkeitsvergleiche verwendet werden kann.
Fine-Tuning:: Der Prozess, ein vortrainiertes Modell mit spezifischen Daten anzupassen, um es für bestimmte Aufgaben zu optimieren.
RAG:: Retrieval-Augmented Generation - eine Technik, die LLMs mit externen Informationsquellen kombiniert, um genauere Antworten zu generieren.
Semantic Kernel:: Ein Open-Source-Framework von Microsoft zur Integration von KI-Diensten in Anwendungen.
