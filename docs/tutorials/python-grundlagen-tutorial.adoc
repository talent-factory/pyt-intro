== Einführung in Python

=== Was ist Python?

Python ist eine vielseitige, interpretierte Programmiersprache, die für ihre klare Syntax und Lesbarkeit bekannt ist. 
Sie wurde 1991 von Guido van Rossum entwickelt und hat sich zu einer der beliebtesten Programmiersprachen 
für verschiedenste Anwendungsbereiche entwickelt.

[IMPORTANT]
====
Python ist eine interpretierte Sprache, was bedeutet, dass der Code zur Laufzeit ausgeführt wird, 
ohne dass eine vorherige Kompilierung nötig ist.
====

=== Warum Python lernen?

* *Einfach zu erlernen*: Klare, lesbare Syntax
* *Vielseitig*: Geeignet für Webentwicklung, Datenanalyse, KI, Automatisierung, etc.
* *Große Community*: Umfangreiche Dokumentation und zahlreiche Bibliotheken
* *Hohe Produktivität*: Schnelle Entwicklung und Prototyping
* *Plattformunabhängig*: Läuft auf Windows, MacOS, Linux und anderen Systemen

=== Variablen und Datentypen

Python verwendet dynamische Typisierung, d.h. Sie müssen den Datentyp einer Variable nicht explizit deklarieren.

[source,python]
----
# Grundlegende Datentypen
name = "Anna"                  # String (Zeichenkette)
alter = 28                     # Integer (Ganzzahl)
groesse = 1.75                 # Float (Gleitkommazahl)
ist_student = True             # Boolean (Wahrheitswert)

# Ausgabe mit Typinformationen
print(f"Name: {name}, Typ: {type(name)}")
print(f"Alter: {alter}, Typ: {type(alter)}")
print(f"Größe: {groesse}, Typ: {type(groesse)}")
print(f"Student: {ist_student}, Typ: {type(ist_student)}")
----

[cols="1,3,2", options="header"]
|===
|Datentyp |Beschreibung |Beispiel
|`str` |Zeichenketten (Text) |`"Hallo"`, `'Welt'`
|`int` |Ganzzahlen |`42`, `-7`
|`float` |Gleitkommazahlen |`3.14`, `-0.001`
|`bool` |Wahrheitswerte |`True`, `False`
|`list` |Veränderbare Sequenz |`[1, 2, 3]`
|`tuple` |Unveränderbare Sequenz |`(1, 2, 3)`
|`dict` |Schlüssel-Wert-Paare |`{"name": "Max", "alter": 30}`
|`set` |Ungeordnete Sammlung einzigartiger Elemente |`{1, 2, 3}`
|`None` |Repräsentiert "kein Wert" |`None`
|===

=== Stringverarbeitung

Strings sind in Python sehr mächtig und bieten viele integrierte Methoden:

[source,python]
----
text = "Python Programmierung"

# Grundlegende String-Operationen
print(len(text))                  # Länge: 21
print(text.upper())               # PYTHON PROGRAMMIERUNG
print(text.lower())               # python programmierung
print(text.replace("Python", "Einfache"))  # Einfache Programmierung

# String-Formatierung
name = "Maria"
alter = 32
# f-Strings (ab Python 3.6)
print(f"{name} ist {alter} Jahre alt.")
# format()-Methode
print("{} ist {} Jahre alt.".format(name, alter))
# %-Notation (ältere Methode)
print("%s ist %d Jahre alt." % (name, alter))

# String-Indexierung und Slicing
s = "Hallo Welt"
print(s[0])      # H (erstes Zeichen)
print(s[-1])     # t (letztes Zeichen)
print(s[0:5])    # Hallo (Zeichen 0 bis 4)
print(s[6:])     # Welt (Zeichen 6 bis Ende)
print(s[:5])     # Hallo (Anfang bis Zeichen 4)
----

[CAUTION]
====
In Python beginnt die Indexierung bei 0, nicht bei 1!
====

=== Listen und Sammlungen

Listen sind eine der wichtigsten Datenstrukturen in Python:

[source,python]
----
# Listen erstellen
zahlen = [1, 2, 3, 4, 5]
namen = ["Anna", "Ben", "Clara"]
gemischt = [1, "Text", True, 3.14]

# Auf Listenelemente zugreifen
print(zahlen[0])        # Erstes Element: 1
print(namen[-1])        # Letztes Element: Clara

# Listen modifizieren
zahlen.append(6)        # Hinzufügen: [1, 2, 3, 4, 5, 6]
zahlen.insert(0, 0)     # Einfügen an Position: [0, 1, 2, 3, 4, 5, 6]
zahlen.remove(3)        # Entfernen nach Wert: [0, 1, 2, 4, 5, 6]
popped = zahlen.pop()   # Entfernen und zurückgeben: 6, Liste wird zu [0, 1, 2, 4, 5]
zahlen.sort()           # Sortieren: [0, 1, 2, 4, 5]
zahlen.reverse()        # Umkehren: [5, 4, 2, 1, 0]

# Listenoperationen
a = [1, 2, 3]
b = [4, 5]
c = a + b               # Verketten: [1, 2, 3, 4, 5]
d = a * 3               # Wiederholen: [1, 2, 3, 1, 2, 3, 1, 2, 3]

# Listen-Comprehensions (elegante Listenerstellung)
quadrate = [x**2 for x in range(1, 6)]  # [1, 4, 9, 16, 25]
gerade = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
----

Neben Listen gibt es weitere wichtige Sammlungstypen:

# For-Schleifen
for i in range(5):  # Zahlen 0 bis 4

namen = ["Anna", "Ben", "Clara"]

for i, name in enumerate(namen):
    print(f"{i+1}. {name}")

count = 0

    print(count, end=" ")
    count += 1  # Inkrementieren, um Endlosschleife zu vermeiden

=== Funktionen

Funktionen sind ein zentrales Konzept in Python, um Code zu organisieren und wiederzuverwenden:

[source,python]
----
# Einfache Funktion definieren
def gruss():
    print("Hallo, Welt!")

# Funktionsaufruf

# Funktion mit Parametern
def begruessung(name):
    print(f"Hallo, {name}!")

begruessung("Maria")  # Ausgabe: Hallo, Maria!

# Funktion mit Rückgabewert
def quadrat(x):
    return x * x

ergebnis = quadrat(5)
print(ergebnis)  # Ausgabe: 25

# Funktion mit Standardwerten
def begruessung_mit_titel(name, titel="Herr"):
    print(f"Guten Tag, {titel} {name}!")

begruessung_mit_titel("Schmidt")           # Guten Tag, Herr Schmidt!
begruessung_mit_titel("Müller", "Frau")    # Guten Tag, Frau Müller!

def summe(*zahlen):
    return sum(zahlen)

print(summe(1, 2, 3, 4, 5))  # 15

def person_info(**info):

def taschenrechner():

    print("Einfacher Taschenrechner")

=== Projekt: Todo-Liste

Implementieren Sie eine einfache Todo-Liste-Anwendung mit Speicherfunktion:

[source,python]
----
import json
import os

class TodoListe:
    """Eine einfache Todo-Listen-Anwendung mit Datei-Speicherfunktion."""
    
    def __init__(self, dateiname="todos.json"):
        """Initialisiert die Todo-Liste."""
        self.dateiname = dateiname
        self.todos = []
        self.laden()
    
    def laden(self):
        """Lädt die Todo-Liste aus einer JSON-Datei."""
        if os.path.exists(self.dateiname):
            try:
                with open(self.dateiname, "r") as datei:
                    self.todos = json.load(datei)
            except json.JSONDecodeError:
                print("Fehler beim Laden der Datei. Starte mit leerer Liste.")
                self.todos = []
    
    def speichern(self):
        """Speichert die Todo-Liste in einer JSON-Datei."""
        with open(self.dateiname, "w") as datei:
            json.dump(self.todos, datei)
    
    def hinzufuegen(self, beschreibung, prioritaet=1):
        """Fügt ein neues Todo zur Liste hinzu."""
        todo = {
            "beschreibung": beschreibung,
            "prioritaet": prioritaet,
            "erledigt": False
        }
        self.todos.append(todo)
        self.speichern()
    
    def entfernen(self, index):
        """Entfernt ein Todo anhand seines Index."""
        if 0 <= index < len(self.todos):
            del self.todos[index]
            self.speichern()
            return True
        return False
    
    def erledigt_markieren(self, index):
        """Markiert ein Todo als erledigt."""
        if 0 <= index < len(self.todos):
            self.todos[index]["erledigt"] = True
            self.speichern()
            return True
        return False
    
    def anzeigen(self):
        """Zeigt alle Todos an."""
        if not self.todos:
            print("Keine Todos vorhanden.")
            return
        
        print("\nTodo-Liste:")
        print("------------")
        for i, todo in enumerate(self.todos):
            status = "✓" if todo["erledigt"] else " "
            print(f"{i+1}. [{status}] ({todo['prioritaet']}) {todo['beschreibung']}")
    
    def menu(self):
        """Zeigt das Hauptmenü der Todo-Liste an."""
        while True:
            print("\nTodo-Listen-Manager")
            print("-------------------")
            print("1. Alle Todos anzeigen")
            print("2. Neues Todo hinzufügen")
            print("3. Todo als erledigt markieren")
            print("4. Todo entfernen")
            print("5. Beenden")
            
            wahl = input("\nWählen Sie eine Option (1-5): ")
            
            if wahl == "1":
                self.anzeigen()
            
            elif wahl == "2":
                beschreibung = input("Beschreibung: ")
                try:
                    prioritaet = int(input("Priorität (1-5, Standard: 1): ") or "1")
                    if not 1 <= prioritaet <= 5:
                        print("Ungültige Priorität. Verwende 1.")
                        prioritaet = 1
                except ValueError:
                    print("Ungültige Eingabe. Verwende Priorität 1.")
                    prioritaet = 1
                
                self.hinzufuegen(beschreibung, prioritaet)
                print(f"Todo '{beschreibung}' hinzugefügt.")
            
            elif wahl == "3":
                self.anzeigen()
                try:
                    index = int(input("\nWelches Todo ist erledigt? (Nr.): ")) - 1
                    if self.erledigt_markieren(index):
                        print("Todo als erledigt markiert.")
                    else:
                        print("Ungültige Todo-Nummer.")
                except ValueError:
                    print("Bitte geben Sie eine Zahl ein.")
            
            elif wahl == "4":
                self.anzeigen()
                try:
                    index = int(input("\nWelches Todo soll entfernt werden? (Nr.): ")) - 1
                    if self.entfernen(index):
                        print("Todo entfernt.")
                    else:
                        print("Ungültige Todo-Nummer.")
                except ValueError:
                    print("Bitte geben Sie eine Zahl ein.")
            
            elif wahl == "5":
                print("Auf Wiedersehen!")
                break
            
            else:
                print("Ungültige Eingabe. Bitte wählen Sie eine Option zwischen 1 und 5.")

# Starten der Todo-Liste
if __name__ == "__main__":
    todo_liste = TodoListe()
    todo_liste.menu()

def zinseszins_berechnen(anfangsbetrag, zinssatz, perioden_pro_jahr, jahre):
    """
    Berechnet den Endbetrag einer Investition mit Zinseszins.
    
    Args:
        anfangsbetrag (float): Der Anfangsbetrag der Investition
        zinssatz (float): Der jährliche Zinssatz als Dezimalzahl (z.B. 0.05 für 5%)
        perioden_pro_jahr (int): Anzahl der Zinsperioden pro Jahr
        jahre (int): Anzahl der Jahre
        
    Returns:
        float: Der Endbetrag nach der angegebenen Zeit
    """
    endbetrag = anfangsbetrag * (1 + zinssatz / perioden_pro_jahr) ** (perioden_pro_jahr * jahre)
    return round(endbetrag, 2)

# Testfall: 1000€ bei 5% Zinsen, vierteljährlicher Verzinsung über 10 Jahre
print(zinseszins_berechnen(1000, 0.05, 4, 10))  # Ausgabe: 1648.09

def passwort_pruefen(passwort):
    """
    Prüft, ob ein Passwort den Sicherheitsanforderungen entspricht.
    
    Args:
        passwort (str): Das zu prüfende Passwort
        
    Returns:
        bool: True, wenn das Passwort stark ist, sonst False
    """
    # Prüfen der Mindestlänge
    if len(passwort) < 8:
        return False
    
    # Flags für die Anforderungen
    hat_grossbuchstaben = False
    hat_kleinbuchstaben = False
    hat_zahl = False
    hat_sonderzeichen = False
    
    # Prüfen jedes Zeichens
    for zeichen in passwort:
        if zeichen.isupper():
            hat_grossbuchstaben = True
        elif zeichen.islower():
            hat_kleinbuchstaben = True
        elif zeichen.isdigit():
            hat_zahl = True
        elif not zeichen.isalnum():  # Nicht alphanumerisch = Sonderzeichen
            hat_sonderzeichen = True
    
    # Alle Anforderungen müssen erfüllt sein
    return (hat_grossbuchstaben and hat_kleinbuchstaben and 
            hat_zahl and hat_sonderzeichen)

# Testfälle

    "abcABC123",           # Kein Sonderzeichen

]

def fakultaet(n):
    """
    Berechnet die Fakultät einer Zahl n (n!).
    
    Args:
        n (int): Eine nicht-negative Ganzzahl
        
    Returns:
        int: Die Fakultät von n
    """
    if n < 0:
        raise ValueError("Fakultät ist nur für nicht-negative Zahlen definiert")
    if n == 0 or n == 1:
        return 1
    
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def fibonacci(n):
    """
    Gibt die n-te Fibonacci-Zahl zurück.
    
    Args:
        n (int): Eine positive Ganzzahl
        
    Returns:
        int: Die n-te Fibonacci-Zahl
    """
    if n <= 0:
        raise ValueError("Fibonacci ist nur für positive Ganzzahlen definiert")
    if n == 1:
        return 0
    if n == 2:
        return 1
    
    a, b = 0, 1
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b

def ist_primzahl(n):
    """
    Prüft, ob eine Zahl eine Primzahl ist.
    
    Args:
        n (int): Eine zu prüfende ganze Zahl
        
    Returns:
        bool: True, wenn n eine Primzahl ist, sonst False
    """
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

from collections import Counter

def datei_analysieren(dateipfad):
    """
    Analysiert eine Textdatei und gibt Statistiken zurück.
    
    Args:
        dateipfad (str): Pfad zur zu analysierenden Datei
        
    Returns:
        dict: Statistiken der Datei
    """
    try:
        with open(dateipfad, 'r', encoding='utf-8') as datei:
            # Datei einlesen
            inhalt = datei.read()
            zeilen = inhalt.split('\n')
            
            # Zeichen zählen (inkl. Leerzeichen)
            zeichen_anzahl = len(inhalt)
            
            # Wörter zählen
            woerter = inhalt.lower().split()
            woerter_anzahl = len(woerter)
            
            # Häufigste Wörter finden
            woerter_zaehler = Counter(woerter)
            top_woerter = woerter_zaehler.most_common(5)
            
            return {
                'zeilen': len(zeilen),
                'woerter': woerter_anzahl,
                'zeichen': zeichen_anzahl,
                'top_woerter': top_woerter
            }
            
    except FileNotFoundError:
        print(f"Fehler: Die Datei '{dateipfad}' wurde nicht gefunden.")
        return {
            'zeilen': 0,
            'woerter': 0,
            'zeichen': 0,
            'top_woerter': []
        }
    except Exception as e:
        print(f"Ein Fehler ist aufgetreten: {e}")
        return {
            'zeilen': 0,
            'woerter': 0,
            'zeichen': 0,
            'top_woerter': []
        }

# Testfall (mit einer vorhandenen Textdatei)
statistik = datei_analysieren("beispiel.txt")
print(f"Zeilen: {statistik['zeilen']}")
print(f"Wörter: {statistik['woerter']}")
print(f"Zeichen: {statistik['zeichen']}")
print("Top 5 Wörter:")
for wort, anzahl in statistik['top_woerter']:
    print(f"  {wort}: {anzahl}")
