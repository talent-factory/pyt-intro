== Beschreibung

In dieser Aufgabe erstellen Sie mehrere Funktionen, die zusammen einen einfachen Rechner bilden.

== Aufgabenstellung

1. Erstellen Sie vier Funktionen:
   * `addiere(a, b)`: Gibt die Summe von a und b zurück
   * `subtrahiere(a, b)`: Gibt die Differenz von a und b zurück (a - b)
   * `multipliziere(a, b)`: Gibt das Produkt von a und b zurück
   * `dividiere(a, b)`: Gibt den Quotienten von a und b zurück (a / b)

2. Achten Sie bei der Funktion `dividiere` darauf, dass eine Division durch 0 abgefangen wird. In diesem Fall soll die Funktion den Text "Division durch 0 nicht möglich" zurückgeben.

3. Erstellen Sie eine weitere Funktion `rechner(operation, a, b)`, die:
   * einen Parameter `operation` entgegennimmt (mögliche Werte: "+", "-", "*", "/")
   * je nach übergebener Operation die entsprechende Funktion aufruft
   * das Ergebnis zurückgibt
   * bei einer ungültigen Operation den Text "Ungültige Operation" zurückgibt
